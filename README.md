# NetPult Mobile (Android, APK)

Мобильное приложение на Python (Flet). Ставится на телефон как обычный APK,
ходит к роутеру напрямую по локальной сети — сервер не нужен.

## Что умеет

- Список устройств в домашней сети: имя, IP, MAC, Wi-Fi-сеть, скорость линка.
- Кнопка «Отключить» / «Вернуть» — режет устройству доступ к сети на роутере.
- Настройки роутера хранятся на телефоне (адрес, логин, пароль).

Поддерживается **Keenetic** (проверено на KN-1610, KeeneticOS 3.8.5).
Дальше по плану: OpenWrt (ubus), Asus, MikroTik.

## Пресеты моделей

В профиле есть выпадающий список **«Модель роутера»**: выбрал Keenetic, OpenWrt,
Asus или MikroTik — протокол, порт и команды заполнились сами. Ничего вводить
руками не нужно, кроме адреса и админских данных.

| Пресет | Что подставляет |
|---|---|
| Keenetic | родной протокол, команды не нужны |
| OpenWrt / Xiaomi на OpenWrt | `cat /proc/net/arp` + блокировка через `iptables` |
| Asus (AsusWRT) | то же, telnet включается в веб-интерфейсе |
| MikroTik | правила firewall RouterOS |
| Xiaomi (заводская) | пока не поддерживается — нужен адаптер под их API |
| Другое | пустые поля, команды вводишь сам |

Любое поле после автозаполнения можно поправить вручную.

## Протоколы: как подключить «любой» роутер

Единого протокола у роутеров нет, поэтому в профиле есть выбор:

| Протокол | Что это | Кому подходит |
|---|---|---|
| **Keenetic (из коробки)** | родной CLI по telnet | все Keenetic |
| **Другой роутер (telnet-команды)** | вы сами задаёте три команды | OpenWrt, старые Xiaomi с telnet, Asus/TP-Link с telnet, любые Linux-роутеры |

Для второго режима заполняются три поля, `{mac}` подставляется автоматически:

```
Список устройств:      cat /proc/net/arp
Заблокировать:         iptables -I FORWARD -m mac --mac-source {mac} -j DROP
Разблокировать:        iptables -D FORWARD -m mac --mac-source {mac} -j DROP
```

Если роутер не отдаёт список клиентов, устройства добавляются вручную кнопкой
«добавить по MAC» — блокировка всё равно работает.

Ограничения, о которых честно:

* **SSH не поддерживается** — на Android для него нужна криптобиблиотека,
  которой нет в сборке Flet. Поэтому режим «другой роутер» работает по telnet.
* **Xiaomi** по умолчанию не имеет ни telnet, ни SSH. Для них нужен отдельный
  адаптер под их HTTP API (miwifi) — сделаем, когда будет доступ к роутеру
  для проверки.
## Как пользоваться

1. Нажать «+» в разделе **Роутеры**: название (например «Дом» или «Мама»), адрес
   (`192.168.1.1`), логин и пароль администратора → «Сохранить».
2. Нажать **Подключить** — появится список устройств (пока приложение не подключено,
   список пуст).
3. Кнопкой **Отключить/Вернуть** можно резать доступ вручную.
4. Кнопка с часами у устройства открывает **расписание**: включить, указать
   «отключать в 00:00» и «включать в 08:00». Пока приложение запущено, оно само
   применяет правило каждые 20 секунд.

Несколько роутеров хранятся отдельно: правила расписания привязаны к адресу
роутера, при переключении профиля они не теряются.

## Ограничение расписания

Планировщик работает внутри приложения: Android может выгрузить его из памяти,
если приложение долго в фоне. Для гарантированного отключения по времени нужен
серверный режим (python-версия из папки `netpult`) или расписание на самом
роутере — его добавим после проверки на живом Keenetic.
## Запуск на компьютере (быстрая проверка UI)

```bash
cd netpult-mobile
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt

flet run src/main.py
```

Откроется окно приложения — можно сразу потыкать список и кнопки.

## Сборка APK

Нужно один раз поставить:

1. **Flutter SDK** (стабильная ветка) и добавить `flutter\bin` в PATH.
2. **Android SDK** (проще всего через Android Studio) + JDK 17.
3. Проверить: `flutter doctor` — должно быть без ошибок по Android.

Потом:

```bash
cd netpult-mobile
pip install -r requirements.txt
flet build apk --project netpult --module-name main
```

Готовый файл появится в `build/apk/`. Его можно закинуть на телефон и установить
(Android спросит разрешение на установку из неизвестного источника).

Для публикации в Google Play/RuStore нужен подписанный релиз:

```bash
flet build apk --release --android-signing-key-store path\to\key.jks ...
```

или `flet build aab` для Play.

## Структура

```
src/main.py            — UI на Flet: настройки, список устройств, блокировка
src/netpult/keenetic.py — клиент CLI роутера Keenetic (telnet), разбор устройств
pyproject.toml         — метаданные сборки APK
```

## Важно знать

- Телефон и роутер должны быть в одной сети (домашний Wi-Fi). Из мобильного
  интернета роутер недоступен.
- Логин/пароль роутера хранятся в `client_storage` приложения. Это не шифрованное
  хранилище Android — для личного пользования нормально, для публикации стоит
  перейти на `flutter_secure_storage` через flet-плагин.
- Команда блокировки: `ip hotspot host <mac> deny`, возврат — `permit`.
  Устройство остаётся видимым в списке, но без доступа к сети.
